# Sovereign-L

Exact integer routing on a discrete lattice, with a multilevel extension, an
assembler and a small virtual machine.

This repository is a **software reference model**. It makes no performance
claim, no hardware claim and no physical claim. What it does claim is listed in
[`docs/SCOPE.md`](docs/SCOPE.md) §1 and every item there is enforced by a test.

## The idea in one paragraph

Take a cell holding a non-negative integer `n`. Give it `k` ordered neighbours.
Split `n` as `n = k*q + r` and give every neighbour `q`, with one extra unit to
the first `r` of them. Empty the source by exactly `n`. Nothing is created,
nothing is lost, and no floating-point value ever appears. That is the whole
operator. Everything else in this repository is a way of using it, checking it,
or executing it.

```
27 -> [4, 4, 4, 3, 3, 3, 3, 3]      sum = 27, spread = 1
```

## Library use

```python
from sovereign import LatticeMemory, CRCEngine

memory = LatticeMemory(dims=4)
engine = CRCEngine(memory)

memory.write((0, 0, 0, 0), 27)
engine.connect((0, 0, 0, 0))
engine.resonate(27)          # (4, 4, 4, 3, 3, 3, 3, 3)
engine.collapse()            # True
```

On a finite domain, declare the boundary policy:

```python
from sovereign import Boundary, LatticeMemory, CRCEngine

memory = LatticeMemory(dims=4, extents=(8, 8, 8, 8), policy=Boundary.PERIODIC)
engine = CRCEngine(memory)
start = memory.total()
engine.sweep()                       # simultaneous update of every cell
assert memory.total() == start       # exact, not approximate
```

Multilevel:

```python
from sovereign import Hierarchy

hierarchy = Hierarchy(memory)        # block 2x2x2x2, 16 children per parent
hierarchy.vcycle(passes=2)           # restrict, route coarse, prolong
assert memory.total() == start       # raises if it is not
```

## Executing it

An assembly program is assembled to bytes and run on the machine:

```
SET_EXTENT 4 4 4 4
LOAD_VAL 24
STORE_CELL 0 0 0 0
CONNECT 0 0 0 0
RESONATE
COLLAPSE
HALT
```

```python
from sovereign import Assembler, Machine

machine = Machine().run(Assembler().assemble(open("program.sl").read()))
print(machine.ok, machine.mmu.total())
```

`COLLAPSE` traps: if the invariant fails, the machine stops and records the
violation. See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full
instruction set.

## What this is not

It is not a physics model, not a hardware design, not a benchmark result and not
a claim of superiority over any existing system. Earlier material associated
with this line of work claimed a 87.50%–94.44% reduction in bus traffic; those
figures were ratios of hand-assigned counters rather than measurements and are
withdrawn. [`docs/SCOPE.md`](docs/SCOPE.md) §2 records every such withdrawal
explicitly, with the reason.

## Provenance

The routing rule is the largest-remainder rule, long known in apportionment
theory. The contribution this repository can defend is the implementation, the
verification, and — with the work described in `docs/ROADMAP.md` Phase 2 — a
characterisation of the family of rules that satisfy these properties.
